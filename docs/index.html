casekit

Agentic-first case conversion service. Convert between camelCase, snake_case, kebab-case, PascalCase, and 9 more formats. Detect case, convert to all at once. Plain text API, agent-driven, single Go binary.

Endpoints

GET /convert — Convert to specific case

GET /detect — Detect case type

GET /all — Convert to all formats

GET /camel — → camelCase

GET /pascal — → PascalCase

GET /snake — → snake_case

GET /screaming-snake — → SCREAMING_SNAKE

GET /kebab — → kebab-case

GET /screaming-kebab — → SCREAMING-KEBAB

GET /dot — → dot.case

GET /title — → Title Case

GET /sentence — → Sentence case

GET /flat — → flatcase

GET /train — → Train-Case

GET /alternating — → aLtErNaTiNg

GET /inverse — → swap case

Quick Start

# Convert to a specific case
curl "http://localhost:7101/convert?text=hello_world&to=camel"
# camel=helloWorld

# Detect the case type
curl "http://localhost:7101/detect?text=helloWorld"
# detected=camel name=camelCase

# Convert to all formats at once
curl "http://localhost:7101/all?text=helloWorld"
# camel=helloWorld
# pascal=HelloWorld
# snake=hello_world
# screaming_snake=HELLO_WORLD
# kebab=hello-world
# ...

# Direct conversion endpoints
curl "http://localhost:7101/snake?text=helloWorld"
# snake=hello_world
